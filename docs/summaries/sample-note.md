## What the topic is explaining
Recursion basics: functions calling themselves and terminating via base cases.

## What the MCQs are asking
Whether you can identify the termination condition of recursion.

## What it means
Every recursive function needs a simplest-case branch that returns without recursing.

## Most important things to know
- Base case = the exit condition
- Each call shrinks the problem toward that base case
