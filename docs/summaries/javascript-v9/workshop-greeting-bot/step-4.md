#### Step 4

Now, it is time to assign a value to your bot variable.

In previous lessons, you learned how to assign values to variables like this:

variableName = "Here is the value";

Remember that what is on the right side of the assignment operator = is the value that you are assigning to the variable on the left side.

Assign the string "teacherBot" to the bot variable.

Hi there! I am excited to talk to you.

## What the topic is explaining
- This step teaches how to assign a value to a variable in JavaScript.
- The variable is named `bot`.
- The value to assign is the string `"teacherBot"`.
- The assignment operator `=` puts the value on the right side into the variable on the left side.
- Example pattern: `variableName = "value";`

## What the MCQs are asking
- There are no explicit MCQs shown on this page.
- The task is to write the correct assignment statement for the `bot` variable.
- The expected answer is likely: `bot = "teacherBot";`

## What it means
- You are giving the `bot` variable a specific value.
- After assignment, `bot` stores the string `"teacherBot"`.
- This is a basic JavaScript concept: variables can hold values, and values can be assigned using `=`.
- The string is written in quotes because it is text, not a number or variable name.

## Most important things to know
- Use `=` to assign a value to a variable.
- The variable name goes on the left side of `=`.
- The value goes on the right side of `=`.
- Strings must be wrapped in quotes, such as `"teacherBot"`.
- The correct code for this step is: `bot = "teacherBot";`
