#### Step 4

Now, it is time to assign a value to your bot variable.

In previous lessons, you learned how to assign values to variables like this:

variableName = "Here is the value";

Remember that what is on the right side of the assignment operator = is the value that you are assigning to the variable on the left side.

Assign the string "teacherBot" to the bot variable.

Hi there! I am excited to talk to you.

## What the topic is explaining
* Variable assignment in JavaScript using `=`
* The left side is the variable name, the right side is the value being stored
* Creating a `bot` variable and giving it a specific string value
* The value to assign is `"teacherBot"`

## What the MCQs are asking
* No MCQs are provided in the page content for this step

## What it means
* `bot = "teacherBot"` stores the text teacherBot in the variable named bot
* Later code can refer to `bot` and use that string value
* Assignment overwrites any previous value the variable may have had

## Most important things to know
* Use quotes for string values: `"teacherBot"`
* Assignment operator is `=` not `==`
* Variable name on left, value on right
* This step sets up the bot identity used by the greeting bot workshop
