## What the topic is explaining
- This is the first step of a JavaScript workshop where you build a simple “greeting bot.”
- The goal is to print a message to the console using JavaScript.
- It reviews two basic ideas:
  - `console.log()` is used to display output.
  - Strings are text values, usually written inside quotes.
- The example shows how to print a string:
  - `console.log("Hello, World!");`

## What the MCQs are asking
- There are no multiple-choice questions on this page.
- The task is a coding exercise:
  - Add a `console.log()` statement.
  - Make it output the exact string `"Hi there!"`.
  - Include quotes around the message.

## What it means
- You are learning how to make JavaScript produce visible output.
- The “bot” is not advanced yet; it simply says a greeting.
- The important skill is using the correct syntax:
  - `console.log()`
  - A string inside quotes
  - A semicolon at the end
- The expected code is:
  - `console.log("Hi there!");`

## Most important things to know
- `console.log()` prints a value to the console.
- Strings must be wrapped in quotes, such as `"Hi there!"`.
- The output must match exactly:
  - `Hi there!`
- This step introduces the basic pattern for building simple JavaScript programs.
