## What the topic is explaining
- This is Step 1 of a JavaScript workshop where you build a greeting bot.
- It introduces using `console.log()` to print a message to the console.
- It reminds you that text messages are strings and must be wrapped in quotes.

## What the MCQs are asking
- No multiple-choice questions are included on this page.
- The only task is a short coding prompt: add a `console.log()` statement that outputs the string `"Hi there!"`.

## What it means
- You are learning how to make JavaScript produce visible output.
- `console.log()` sends a value or message to the browser’s developer console.
- The string `"Hi there!"` is the exact text the bot should say.
- The quotes are required because JavaScript uses them to identify a string.

## Most important things to know
- Use `console.log("Hi there!");` to complete the step.
- Do not forget the quotes around the message.
- The output must match the requested string exactly.
- This is the first building block for a bot that can “speak” or respond with messages.
