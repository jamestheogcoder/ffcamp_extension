## What the topic is explaining
- This step teaches how to declare a JavaScript variable using `let`.
- The example shows `let greeting;`, which creates a variable named `greeting`.
- The task asks you to create a variable named `bot` using `let`.
- `let` is used because the value of `bot` will be changed later in the workshop.

## What the MCQs are asking
- There are no multiple-choice questions on this page.
- The exercise/test asks you to declare a variable called `bot`.
- The expected answer is a simple variable declaration using `let`.

## What it means
- You are learning the basic syntax for creating a variable in JavaScript.
- `let bot;` means: “create a variable named `bot` and allow its value to be changed later.”
- This is a small setup step for building a greeting bot, where `bot` will likely store a message or value.

## Most important things to know
- Use `let` to declare a variable that may be reassigned later.
- The required declaration is: `let bot;`
- Variable names must match exactly, so it must be `bot`, not `Bot` or `botname`.
- This step is about syntax and variable declaration, not yet about changing the value.
