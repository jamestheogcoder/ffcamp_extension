- This step introduces a simple JavaScript task: making a “greeting bot” print a message.

- It reminds you that strings need quotes, like `"Hello, World!"`.

## What the MCQs are asking
- There are no multiple-choice questions on this page.
- The task asks you to add a `console.log()` statement that outputs the exact string `"Hi there!"`.

## What it means
- You are learning how JavaScript can display text using the console.
- The correct code should be:
  ```js
  console.log("Hi there!");
  ```
- The quotes are required because `"Hi there!"` is a string.

## Most important things to know
- `console.log()` prints a value to the console.
- A string is text wrapped in quotes.
- The output must be exactly `Hi there!`.
- Do not forget the quotes, parentheses, or the message itself.
