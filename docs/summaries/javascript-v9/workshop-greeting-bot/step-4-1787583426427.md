Remember that what is on the right side of the assignment operator = is the value that you are assigning to the variable on the left side.

## What the topic is explaining
- Variable assignment in JavaScript using `=`.
- The right-hand side value is stored in the left-hand side variable name.
- The specific task is to give the variable `bot` the string value `"teacherBot"`.

## What the MCQs are asking

- The step is a coding instruction only, not a multiple-choice question.

## What it means
- `bot = "teacherBot";` means the identifier `bot` now refers to the text teacherBot.
- Assignment does not create a new variable, it sets a value for an existing one.
- The string must be in quotes to be treated as text, not a variable name.

## Most important things to know
- Assignment syntax is `variableName = value;`.
- Value on the right, variable on the left.
- Strings in JavaScript are wrapped in quotes, e.g., `"teacherBot"`.
