#### Step 3

In previous lessons, you learned about the let keyword and how to declare variables in JavaScript.

Here is a reminder of how to declare a variable using the let keyword:

let greeting;

Use the let keyword to declare a variable called bot.

NOTE: You are using let here because later on in the workshop, you will be changing the value of the bot variable.

Hi there! I am excited to talk to you.

## What it means
- `let greeting;` is a declaration that creates a mutable variable named `greeting`
- `let bot;` will create a mutable variable named `bot` that can be assigned later in the workshop
- Using `let` allows reassignment, which is needed for the bot variable as its value will change

## Most important things to know
- `let` declares a block-scoped mutable variable
- Declaration can be separate from initialization
- Choose `let` when the value will be changed later, `const` when it will not
