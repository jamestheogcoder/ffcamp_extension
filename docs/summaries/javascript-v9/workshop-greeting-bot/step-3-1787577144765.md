## What it means
- `let` creates a mutable, block-scoped variable that can be reassigned later
- Declaring `bot` now sets up a place to store the greeting bot's state/value
- The syntax error illustrates that strings must be separated properly, e.g., with `+` or a comma, not glued together

## Most important things to know
- Use `let bot;` to declare the variable, not `const` if reassignment is needed
- `let` is preferred here over `var` for block scoping and modern practice
- A valid `console.log` needs correct string syntax; `"Hi there!"you."` is a parse error
