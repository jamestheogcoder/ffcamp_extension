#### Step 3

In previous lessons, you learned about the let keyword and how to declare variables in JavaScript.

Here is a reminder of how to declare a variable using the let keyword:

let greeting;

Use the let keyword to declare a variable called bot.

NOTE: You are using let here because later on in the workshop, you will be changing the value of the bot variable.

Hi there! I am excited to talk to you.

## What it means
- `let` creates a mutable variable that can be declared now and assigned later
- Choosing `let` signals intent to change the value later in the workshop
- Declaration separates creating a variable name from giving it a value

## Most important things to know
- `let greeting;` declares a variable without initializing it
- Use `let bot;` to create the bot variable as requested
- `let` allows reassignment; `const` would not
