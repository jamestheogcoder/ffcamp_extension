## What it means
- You are learning the basic way JavaScript communicates with the user or developer through the console.
- A string is a piece of text, and it must be enclosed in quotes, such as `"Hi there!"`.
- `console.log("Hi there!")` means: “Display the text Hi there! in the console.”
- This is a foundational skill for debugging and building simple programs.

## Most important things to know
- Use `console.log()` to print a message.
- The message must be a string, so include quotes: `console.log("Hi there!");`
- The exact expected output is `Hi there!`.
- Forgetting the quotes will cause an error because JavaScript will not treat the text as a string.
