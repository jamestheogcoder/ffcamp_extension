## What it means
- `console.log()` sends a string to the browser/Node console for debugging and output
- Strings must be wrapped in quotes `"` or `'` to be recognized as text
- This is the basic I/O pattern for JavaScript programs: write code → log output

## Most important things to know
- `console.log("Hi there!");` is the exact statement required
- Quotes are mandatory; without them JavaScript treats the words as variables
- This step tests basic syntax recall, not logic
