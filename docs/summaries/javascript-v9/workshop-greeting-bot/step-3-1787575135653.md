#### Step 3

In previous lessons, you learned about the let keyword and how to declare variables in JavaScript.

Here is a reminder of how to declare a variable using the let keyword:

let greeting;

Use the let keyword to declare a variable called bot.

NOTE: You are using let here because later on in the workshop, you will be changing the value of the bot variable.

Hi there! I am excited to talk to you.

## What the topic is explaining
- Review of variable declaration with `let` in JavaScript
- How to declare a variable named `bot` using `let`
- Why `let` is chosen over `const` here because the value will be reassigned later in the workshop

## What the MCQs are asking
- No MCQs are present on this page content
- The step is a single coding instruction to declare `let bot;`

## What it means
- `let greeting;` is the syntax pattern being reused
- Declaring `bot` with `let` creates a mutable binding that can be updated later
- This is preparation for building a greeting bot where the variable will hold changing state

## Most important things to know
- `let` allows reassignment; `const` would not
- Declaration is separate from assignment: `let bot;` creates the variable with no initial value
- The workshop is building up a bot step by step, so variable mutability is intentional
