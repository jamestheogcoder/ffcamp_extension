#### Step 3

In previous lessons, you learned about the let keyword and how to declare variables in JavaScript.

Here is a reminder of how to declare a variable using the let keyword:

let greeting;

Use the let keyword to declare a variable called bot.

NOTE: You are using let here because later on in the workshop, you will be changing the value of the bot variable.

Hi there! I am excited to talk to you.

## What the topic is explaining
- Review of variable declaration with `let` in JavaScript
- How to declare a variable: `let greeting;`
- Task to declare a variable named `bot` using `let`
- Reason for using `let` instead of `const` is future reassignment

## What it means
- `let` creates a mutable binding that can be reassigned later in the workshop
- Declaring `bot` now sets up a placeholder that will be given a value and changed later
- Choosing `let` signals intent to mutate, while `const` would prevent reassignment

## Most important things to know
- `let greeting;` is declaration without initialization
- Use `let bot;` to match the required variable name
- `let` is block-scoped and allows reassignment, which is needed for the greeting bot
