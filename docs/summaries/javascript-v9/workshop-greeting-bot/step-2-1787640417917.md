## What it means
- `console.log()` is a JavaScript function used to display information in the console.
- Each `console.log()` call prints one message.
- To make the bot say two things, you need two separate `console.log()` statements.
- The message must be placed inside quotes because it is a string.

## Most important things to know
- Use `console.log("I am excited to talk to you.")` to complete the step.
- The message must match the required text exactly, including punctuation.
- Strings in JavaScript are written inside quotes, such as `"text"`.
- Multiple messages can be printed by writing multiple `console.log()` statements.
