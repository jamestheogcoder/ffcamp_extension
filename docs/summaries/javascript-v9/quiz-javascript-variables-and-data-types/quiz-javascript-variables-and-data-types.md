## What the topic is explaining
- JavaScript is a programming language used for web development, not a markup language or database system.
- Variables store values and can be declared with `let`, `const`, or `var`.
- JavaScript has data types such as `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, and `object`.
- `Double` and `Float` are not separate JavaScript primitive data types; numbers are just `number`.
- Strings are immutable, meaning their characters cannot be changed directly after creation.
- Statements are commonly ended with a semicolon `;`.
- Comments can be single-line with `//` or multi-line with `/* ... */`.
- JavaScript is dynamically typed, meaning the type is inferred from the assigned value.
- `typeof` is used to check the type of a value.
